# Roadmap

BrowserLocal AI Bridge is developed from real usage rather than a speculative feature list.

## P0 — working baseline

- Direct-local execution with explicit repository/checkouts allowlists.
- Durable GitHub worker for tasks that must survive browser/session interruption.
- Codex executor with bounded structured results and recovery guards.
- Safe deterministic named recipes for mechanical local operations.

## P1 — current focus

- Dogfood the bridge in real consumers and fix only observed reliability or ergonomics gaps.
- Keep Windows/Linux CI and public contracts stable as executors/connectors evolve.
- Improve contributor experience without adding premature governance.

## Backlog

Additional executors/connectors and richer orchestration belong here until a concrete consumer demonstrates the need.
